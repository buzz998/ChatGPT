# 糖的案卷 · Sugar Case File — Treatment

风格：复古半调案卷（Halftone Dossier，`styles/halftone-dossier/STYLE.md`）
规格：1080×1920 竖屏 · 30 fps · 目标约 80–90 s（最终以配音实测时长为准）· 中文配音 + 烧录字幕 + `.srt` · −14 LUFS
平台：抖音。安全区：顶部 0–170 px 留给状态栏；右侧 x > 930、y 760–1500 是点赞/评论按钮列；底部 y > 1480 是标题/文案区。所有关键信息放在 x 60–900、y 170–1460 之内。

## 1. 三个候选结构

**A. 公诉书（选定）**：整片是一份案卷，被一页一页读出来。开场把奶茶当证物袋立案，嫌疑人“方糖”拍嫌疑人照（身高尺 + 名牌 + 闪光），然后五条罪状各是一张编号证物卡（巨大的半调数字 1–5），每条罪状结束时证物缩成一张拍立得钉到“人体证据板”上；第五条之后镜头拉开，证据板全貌、红线从奶茶连到五个器官（标志镜头）。接着“伪装”用涂黑条揭开，最后宣判盖章、结案归档。
优点：文案本身就是“立案—罪状—宣判—结案”，结构和风格的“指控框架”天然一致；编号证物让 5 条罪状好记。

**B. 体内追踪**：跟着一口奶茶从嘴到胰腺、肝脏、皮肤、牙齿、腰围一路旅行，像监控录像。
放弃原因：旅行的空间叙事需要连续场景和大量过渡，和“一卡一事”的案卷语法冲突；文案的顺序（牙齿在第四）也不是消化道顺序，会显得乱。

**C. 8 发子弹倒计时**：8 块方糖是 8 发子弹，每条罪状打掉一块。
放弃原因：数字游戏抢走注意力，“伪装”和“宣判”两段接不上；5 条罪状对不上 8 块糖。

开场画面、结尾、配乐形状都从题目出发：开场 = 奶茶装进证物袋、立案章砸下；结尾 = 同一个证物袋，盖上“结案”，案卷合上推进抽屉（抽屉里一排“奶茶”案卷 → 这种事天天发生）。

## 2. 一句话与弧线

**Logline**：一杯全糖奶茶被当作证物立案，嫌疑人“糖”被逐条宣读五宗罪、揭穿伪装，最后按膳食指南判定“超标”——但判决不是死刑，而是“别天天喝、别喝全糖”。

- 起：立案 + 嫌疑人照：30 克 vs 血液里只有 4 克（悬念：身体怎么收场？）
- 承：五条罪状，一条比一条贴身（内脏 → 外貌 → 体型）
- 转：它最狡猾的是伪装（“不另外加糖”被揭开，仍有糖）
- 合：宣判越线 → 温和的判决 → 结案归档，回扣开场证物袋

## 3. 对标

- **对标 1：老式警察/法庭纪录片的证物陈列与“案卷翻页”节奏**（如《Making a Murderer》类片头的档案翻拍语法）。学：一张证物一个焦点、编号、档案章、闪光拍照的节奏。不学：任何真实案件、画面、标识。
- **对标 2：60 年代波普印刷海报 / Ben-Day 网点漫画**。学：用网点大小做明暗、套印错位阴影、粗描边角色。不学：具体人物、对白框原画。
- **配乐对标：周杰伦《夜的第七章》的悬疑侦探氛围**。学：小调、钢琴 / 拨弦的固定音型（ostinato）、钟表滴答、低音推进、“案件揭晓”式的停顿。**不学：任何旋律、和弦进行、节奏型、念白方式、采样**。全部原创。

## 4. 设计

**油墨（纸 + 5 色）**：纸 奶油米 `#F1E4C6`；暗墨 深藏青 `#1C2340`（描边、正文、字幕条、暗场）；套印阴影 奶茶焦糖 `#C8834A`；高光 方糖黄 `#F5C518`（关键词、数字）；警报红 `#D8352A`（印章、超标）；辅助 薄荷青 `#3FA7A0`（胰岛素“信使”、健康侧）。
**角色**：嫌疑人“方糖”——圆角立方体，粗描边、白色身体带浅黄阴影面、光泽眼睛，表情：得意眯眼 / 被拍照惊吓 / 狡猾斜眼 / 被判后蔫掉。胰岛素小信使（青色小圆人，背着钥匙）。器官为扁平道具：胰腺、肝脏、胶原弹簧、牙齿、腰带。
**字体**：标题 Noto Serif SC 900（套印阴影 +8/+8）；数字 Bagel Fat One；拟声 ZCOOL KuaiLe；案号/HUD JetBrains Mono 800；字幕条与印章 Noto Sans SC 900。中文字体按用到的字子集化，存到 `fonts/`。
**字幕卡**：深藏青圆角胶囊，焦糖色偏移阴影，米色字，关键词方糖黄。**位置：下三分之一的上沿**——胶囊顶边在 y≈1290，高度一行 112 px / 两行 190 px，x 60–900，避开右侧按钮列和底部标题区。字幕卡就是字幕（承载完整口播句，按句切分）。
**HUD**：左上 `CASE No. 2026-TANG-001` + 章节牌（立案 / 罪状一…），右上 REC 红点 + 日期。顶部从 y=180 开始，避开状态栏。

## 7. 配乐 cue map（原创，参照《夜的第七章》的悬疑侦探氛围）

- 调性 D 小调，**92 BPM**，4/4。一小节 ≈ 2.61 s。
- 乐器（项目自带乐器库 + 风格声音调色板）：钢琴低音区八分音符固定音型（Salamander）、拨弦 pizzicato（VSCO 2 CE）、马林巴式拨音主题（风格原生合成）、合成底鼓 / 军鼓边击 / 响指、方波八分低音、钟表滴答。
- 段落：
  - 0–3 s 立案：低音钢琴单音 + 钟摆滴答，印章处全停。
  - 3–15 s 嫌疑人：pizzicato + 响指“潜行”，低音进入。
  - 15–62.5 s 五宗罪：完整律动（底鼓、边击、方波低音、钢琴固定音型、马林巴主题），每条罪状开头一个军鼓滚奏 + 上扬扫频进网点擦除；第四、五条加 16 分音符踩镲（加速）。
  - 62.5–65 s 证据板：只留长音 pad + 钟表滴答（呼吸）。
  - 65–72.5 s 伪装：抽到只剩低音 + 响指（秘密场景）。
  - 72.5–83 s 宣判：上升音阶 → 0.6 s 静默 → 印章砸下后完整律动回来一小节。
  - 83–90.5 s 结案：马林巴主题以音乐盒铃声收尾，最后一下钢琴低音 + 抽屉关上。
- 人声比音乐高约 10 dB，口播处音乐自动压低。

## 9. 字幕与标题设计

- 标题：每张卡一个大标题（Noto Serif SC 900，140–200 px，左对齐 x=70，套印阴影 +8/+8 焦糖色），例：“立案”“嫌疑人：糖”“罪状一 累垮胰岛素”。
- 字幕卡：如第 4 节；关键词（数字、术语）用方糖黄。每行 ≤ 13 个汉字，最多两行。
- 数字字幕用阿拉伯数字（30 克、4 克、18%、100 克、50 克、25 克），配音文本用汉字读法。

## 10. 已知不确定点

1. **配音音色与语速**：上游仓库里没有 `films/tap-water-journey`，无法查到它用的声音。本库中文默认是 edge-tts `zh-CN-XiaoxiaoNeural`、语速 +0%；按默认语速全片约 100 s，要到 ~85 s 需约 +20%。
2. **云端网络**：edge-tts（speech.platform.bing.com）与语音校对模型（huggingface.co）当前被环境网络策略拦截。
3. **数据口径**：文案数字由用户提供，按原文使用，不做改动（“约 18%”“每 100 克约 4 克”等）。
